# 📊 Project Cost Analysis Dashboard

![SQL](https://img.shields.io/badge/SQL-PostgreSQL-blue)
![Looker Studio](https://img.shields.io/badge/Looker%20Studio-Dashboard-orange)
![Google Sheets](https://img.shields.io/badge/Google%20Sheets-Integration-green)

Project ini bertujuan untuk menganalisis perbandingan antara **Budget** dan **Actual Cost** dalam tata kelola biaya proyek. Data diolah menggunakan query **PostgreSQL** dan divisualisasikan secara interaktif melalui **Looker Studio**.

* **Data Prep / Storage:** Google Sheets
* **Visualization:** Looker Studio

---

## 💡 Key Insights & Business Highlights
* **Over-Budget Highlight:** Kategori **IT Equipment** mencatatkan pembengkakan biaya (*over-budget*) terbesar, yaitu mencapai **Rp171,93 Juta** atau **1,44%** lebih tinggi dari anggaran yang direncanakan.
